Head and Body

cabeza: Head contiene lo que no puede ver el usuario. (tecnico)
cuerpo: Body contiene lo que va a poder ver el usuario. (visual)
referencia: https://www.ionos.mx/digitalguide/paginas-web/desarrollo-web/html-body/

BASIC TAGS

section: Se usa para agrupar contenido que pertenece al mismo grupo y juntarlos en uno.
ARTICLE: Pieza independiente que puede ser distribuida por su cuenta.
aside: Contenido que esta indirectamente relacionado con el principal.
HEADER: Tiene contenido introductorio. Normalmente tiene titulos, links o nombres.
footer: COntiene informacion del auto, copyright, links o contactos.

CSS sirve para determinar el diseño del pagina.

Proposito CSS

Diseñar y dar estilo a las paginas web.

apLICACION DE css

Internal: tienes que agregar style y head tag. seccion en el html funciona mejor pára una pagina sola.
external: linkeas tus html a un css externo.
inline: se usa para darle estilo a un atributo de html especifico.
Referencia: https://www.hostinger.com/tutorials/difference-between-inline-external-and-internal-css

Selector / CSS rule

Selector: indica que elementos html se quieren cambiar. CSS rule: selector + bloque + declaración. Referencia: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Syntax/At-rules

Class VS ID

Class: a comparacion del id que solo es uno la clase se puede aplicar a varios atributos en una pagina.
ID: numero unico. identificador para un elemento html.
Referencia:https://www.codecademy.com/article/classes-vs-ids

CSS Box model

todo esta dentro de cajas como por capas y entender esto ayuda a mejorar el diseño de las paginas.
Referencia:https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model

media queries

detecta y adapta el diseño dependiendo del tamaño del dispositvo (celular, computadora, etc) Referencia:https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Using
